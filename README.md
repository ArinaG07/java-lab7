# Лабораторная работа № 7. Работа с базами данных через JDBC

**ФИО автора:** Гуляева Арина Евгеньевна

**Группа:** ФИТ-251

## Описание
Приложение демонстрирует работу с базой данных H2 через JDBC. Реализованы все 8 заданий: от простых SQL-запросов до загрузки данных из JSON и удаления таблиц. Используется H2 в режиме in-memory (в оперативной памяти).

## СУБД
Используется **H2 Database** (версия 2.2.224). Режим: **в памяти** (`jdbc:h2:mem:testdb`).

## Порядок подготовки базы данных
База данных и таблицы создаются автоматически при запуске программы. Скрипт `music-create.sql` и файл `books.json` находятся в папке `src/main/resources/`.

## Команды для сборки и запуска
1. Сборка проекта:
   `mvn clean package`
2. Запуск приложения:
   `java -jar target/java-lab7-1.0-SNAPSHOT.jar`
